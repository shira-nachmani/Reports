# Attendance Report Parser 📊

מערכת אוטומטית ומודולרית בשפת Python לחילוץ, עיבוד וסיווג נתוני נוכחות מתוך דוחות PDF (סרוקים או ממוחשבים), והמרתם לטבלת Excel מובנית ונקייה.

המערכת תומכת בזיהוי מורכב של סוגי דוחות שונים (כגון **Type A** ו־**Type B**) בעלי מבנה עמודות ושדות שונים, ומבצעת את העיבוד מקצה לקצה בצורה יציבה, תקנית ומודולרית.

## ✨ תכונות מרכזיות
- **חילוץ טקסט מבוסס OCR:** תמיכה מלאה בדוחות סרוקים בעברית באמצעות מנוע Tesseract ו־Poppler.
- **סיווג אוטומטי (Report Classifier):** זיהוי דינמי של סוג הדו"ח (Type A / Type B) על פי מילות מפתח ומאפייני מבנה ייחודיים.
- **מבנה נתונים תקני (Dataclasses):** ייצוג כל שורת נוכחות באמצעות אובייקטים מובנים להבטחת עקביות ואיכות הנתונים.
- **חילוץ שדות מתקדם:** פענוח תאריכים, ימים בשבוע, שעות כניסה ויציאה, חישוב סה"כ שעות וזיהוי הערות.
- **ייצוא מרוכז ל־Excel:** שמירת כל הנתונים המעובדים בטבלה מסודרת באמצעות ספריית `pandas`.

## 🏗 ארכיטקטורה וזרימת הנתונים (Pipeline)

המעבר מקובץ PDF גולמי לקובץ Excel סופי מבוצע בצינור עיבוד (Pipeline) מובנה:

1. **OCR Processing (`pdf2image` + `pytesseract`):** 
   המרת דפי ה־PDF לתמונה וחילוץ הטקסט בעברית בתצורה המותאמת לטבלאות (`--psm 6`).
2. **Classification (`detect_report_type`):** 
   ניתוח הטקסט הגולמי וסיווג הדו"ח לסוג המתאים לפי עמודות ומאפיינים (כגון מילות מפתח "מקום", "150%", "יום בשבוע", "הערות").
3. **Parsing Layer:** 
   הפעלת פונקציית פירסור ייעודית בהתאם לסוג הדו"ח שזוהה, וחילוץ השדות בצורה מבוקרת.
4. **Data Modeling (`AttendanceRecord`):** 
   אחסון הנתונים במודל נתונים תקני.
5. **Export (`pandas`):** 
   איחוד כל הרשומות ל־DataFrame וייצוא לקובץ Excel סופי (`attendance_report.xlsx`).

## 🛠 דרישות קדם (Prerequisites)

כדי להריץ את הפרויקט בסביבה מקומית יש לוודא שהכלים הבאים מותקנים:
- **Python** (גרסה 3.10 ומעלה)
- **Tesseract-OCR** (מנוע OCR כולל חבילת השפה העברית `heb`)
- **Poppler** (כלי עזר להמרת PDF לתמונות)
